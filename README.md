# Gemini Agent Harness

**A production-minded Gemini Antigravity agent harness for new and established repositories.**

This template optimizes your repository for Gemini Antigravity, focusing on token efficiency, precise routing, and strict verification guardrails.

## Why use it

- **Gemini-First**: Optimized for Antigravity's context windows and capabilities.
- **Durable Rules**: `AGENTS.md` provides strict routing and boundaries.
- **Progressive Skills**: Workflows load dynamically only when needed.
- **Strict Guardrails**: Ensures agents do not leak credentials or bypass verification.

## Getting Started

1. Clone or adopt this template in your repository.
2. Ensure you are using Gemini Antigravity IDE or CLI.
3. Review `AGENTS.md` and `.gemini/config.toml` before starting.
4. Verify the baseline:
   - `./scripts/lint.sh`
   - `./scripts/test.sh`
   - `./scripts/security.sh`

For detailed setup instructions, see [START_HERE.md](START_HERE.md).
